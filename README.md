# TutorPlatform

Платформа для онлайн-работы репетитора с учениками.

---

## Локальный запуск (основной режим)

```bash
docker compose up -d
```

После запуска сайт открывается на [http://localhost:3004](http://localhost:3004), API —
на `http://localhost:3001/api`. Все сервисы, база данных, файлы MinIO, модель
Whisper и модель Ollama работают в Docker на этом компьютере. Аудио уроков
дополнительно архивируется в `D:\job\website-data\audio`. Для первого запуска
понадобится интернет, чтобы Docker скачал образы и AI-модели; далее приложения
используют локальные контейнеры и сохранённые модели.

Первый запуск после изменения исходников выполняется с пересборкой:

```bash
docker compose up -d --build
```

Все контейнеры используют `restart: unless-stopped`. Чтобы стек запускался
сам после входа в Windows, один раз выполните из PowerShell в корне проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-local-autostart.ps1
```

Скрипт создаёт задачу для текущего пользователя: она ждёт Docker Engine и
запускает тот же `docker compose up -d`. Данные сохраняются в Docker volumes и
на диске `D:\job\website-data\audio`; команда `docker compose down` не удаляет
эти данные.

Конфигурация в `deploy/` оставлена для прежнего VPS и не используется локальным
compose. Локальный режим не обращается к VPS.

Чтобы гонять API с хоста (`npm run dev:backend`), достаточно инфраструктуры:

```bash
docker compose up -d postgres minio redis livekit
npm run dev:backend
npm run dev:frontend
```

Postgres с хоста: `localhost:5433` (не 5432). Скопируйте `backend/.env.example` → `backend/.env`.

Первый запуск скачивает локальные AI-модели (`faster-whisper large-v3-turbo`
и `Qwen3 8B` в docker-compose для разработки). В production по умолчанию
стоят более лёгкие `whisper small` и `qwen2.5:3b` — см. `deploy/README.md`.
Для ускорения на CPU можно задать в `.env` меньшие модели (`WHISPER_MODEL=small`,
`OLLAMA_MODEL=qwen2.5:3b`). `WHISPER_BEAM_SIZE=1` выбран по умолчанию; меньшие
модели распознавания дают более быструю обработку ценой некоторой точности.

## Дополнительный деплой на VPS (easyphys.ru)

На сервере с nginx (и соседними сайтами на :3001/:3002):

```bash
git clone git@github.com:artemsagiyan/private-teacher-website.git
cd private-teacher-website
sudo bash deploy/deploy.sh --yes
```

Скрипт сам:
- ставит Docker / nginx / certbot при необходимости
- генерирует секреты в `deploy/.env.prod`
- поднимает стек с портами, которые **не конфликтуют** с соседними сайтами (backend на `3010`)
- настраивает nginx для `easyphys.ru` + `live.easyphys.ru`
- выпускает HTTPS (Let's Encrypt)

Перед запуском добавь DNS: `live.easyphys.ru` → IP сервера (нужно для видеоуроков).

Опции: `DOMAIN=... EMAIL=you@mail.ru sudo -E bash deploy/deploy.sh`, `--skip-ssl`, `--yes`.

## Как войти

### Ученик — регистрация

1. Открыть http://localhost:3004
2. Нажать **Регистрация**
3. Выбрать вкладку **Ученик**
4. Заполнить имя, фамилию, email, пароль → **Зарегистрироваться**
5. Попадёте в личный кабинет ученика

### Как получить код для регистрации преподавателя

Это делается один раз при первом запуске. Нужно 5 шагов:

---

**Шаг 1** — Зарегистрировать любой аккаунт на сайте

Открыть http://localhost:3004/auth/register → вкладка **Ученик** → заполнить и зарегистрироваться.

---

**Шаг 2** — Сделать этот аккаунт администратором

```bash
docker exec -it tutor_postgres psql -U postgres -d tutor_platform \
  -c "UPDATE users SET role = 'admin' WHERE email = 'ваш@email.com';"
```

---

**Шаг 3** — Войти и получить токен

Открыть http://localhost:3001/api/docs (Swagger UI).

Найти раздел **auth** → `POST /api/auth/login` → нажать **Try it out** → вставить:

```json
{
  "email": "ваш@email.com",
  "password": "ваш_пароль"
}
```

Нажать **Execute**. В ответе скопировать значение `accessToken`.

---

**Шаг 4** — Авторизоваться в Swagger

В Swagger нажать кнопку **Authorize** (правый верхний угол) → вставить скопированный токен → **Authorize**.

---

**Шаг 5** — Создать код для преподавателя

В Swagger найти раздел **admin** → `POST /api/admin/codes` → **Try it out** → вставить:

```json
{
  "expiresInDays": 7
}
```

Нажать **Execute**. В ответе будет поле `code`, например `A1B2C3D4E5`.

---

**Шаг 6** — Зарегистрировать преподавателя

Открыть http://localhost:3004/auth/register → вкладка **Преподаватель** → ввести полученный код в поле «Код преподавателя» → заполнить остальные поля → **Зарегистрироваться**.

---

> **Подключение к БД напрямую** (pgAdmin, DBeaver, TablePlus):
> - Host: `localhost`, Port: `5433`, User: `postgres`, Password: `postgres`, DB: `tutor_platform`

## Типичный сценарий работы

```
1. Зарегистрироваться как ученик
2. Зарегистрироваться как преподаватель (нужен код от Admin)
3. Преподаватель → Дашборд → сгенерировать «Код для учеников»
4. Ученик → «Мой преподаватель» → ввести код → привязаться
5. Преподаватель → Календарь → кликнуть по времени → создать слот
6. Ученик → Календарь → выбрать зелёный слот → Записаться
7. Оба получают уведомления
8. Как только в комнату заходит хотя бы один участник, начинается запись
9. Преподаватель завершает урок кнопкой, либо урок завершается после 30 минут пустой комнаты
10. После любого захода формируется отчёт: с транскриптом при доступной записи или без него, если запись не сохранилась
```

## Запись, транскрипция и отчёты

- **LiveKit Egress** записывает смешанное аудио урока в OGG.
- Войти можно в любое время, в том числе до запланированного начала. Токен LiveKit действует до 8 часов.
- **MinIO** хранит запись, доску, транскрипт и отчёт.
- **faster-whisper** локально распознаёт русскую речь без внешних API.
- **Ollama + Qwen3 8B** локально формирует структурированный отчёт.
- Доска автоматически сохраняется во время занятия и доступна из истории.
- Обработка выполняется в фоне. При временной ошибке сервис делает повторные
  попытки; состояние видно на странице урока.
- Готовый автоматический отчёт появляется в истории уроков и доступен в
  кабинете семьи по приватной ссылке. Если ученик сохранил адрес родителя,
  копия дополнительно отправляется на email. Преподаватель может проверить
  разбор и опубликовать подобранное по импортированному каталогу задание.
- Кабинет семьи показывает запланированные, посещённые и пропущенные занятия,
  прогресс по темам, отчёты, опубликованное ДЗ и начисления. Отчёт можно
  сохранить в PDF через диалог печати браузера. В кабинете доступен чат с
  преподавателем; в аналитике преподавателя можно выбрать период и распечатать
  отчёт.

Полезная диагностика:

```bash
docker compose ps
docker compose logs -f backend egress transcriber ollama-pull
```

На CPU транскрипция часового урока может занять значительное время. Для более
быстрой обработки можно настроить GPU для контейнера `transcriber` и установить
`WHISPER_DEVICE=cuda`, `WHISPER_COMPUTE_TYPE=float16`.


## Стек

- **Frontend**: Next.js 15, React 18, TypeScript, Tailwind CSS, FullCalendar
- **Backend**: NestJS, TypeORM, PostgreSQL
- **Auth**: JWT + Refresh Tokens, Google OAuth (требует настройки)
- **Видео и запись**: LiveKit Server + LiveKit Egress
- **Локальный AI**: faster-whisper + Ollama/Qwen3
- **Хранилище**: MinIO (S3 API)
- **Инфраструктура**: Docker, Docker Compose, Redis

## Google OAuth (опционально)

1. Создать проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включить **Google+ API**
3. Создать OAuth 2.0 credentials
4. В `docker-compose.yml` заменить:

```yaml
GOOGLE_CLIENT_ID: ваш_client_id
GOOGLE_CLIENT_SECRET: ваш_client_secret
GOOGLE_CALLBACK_URL: http://localhost:3001/api/auth/google/callback
```

5. Пересобрать: `docker compose up -d --build backend`
